# Week-8-Python-Assignment
# COVID-19 Patient Data Analysis (Mexico)

This project is a comprehensive data analysis report on patient-level COVID-19 health records from Mexico. It explores trends in mortality, ICU admissions, comorbidities, and demographic patterns using Python’s data analysis tools.


# Project Objectives

- Import and clean real-world COVID-19 health records
-  Perform exploratory data analysis (EDA) to identify trends in:
  - Death rates by age and gender
  - ICU admissions vs survival
  - Comorbidities among death cases
-  Visualize patterns with clear, insightful charts
-  Communicate findings through a well-documented Jupyter Notebook report



##  Tools and Libraries Used

- Python 3.x
- pandas
- matplotlib
- seaborn
- Jupyter Notebook
